## Project Description
NutriTrack is a nutrition and fitness tracking application designed to help users monitor their food intake, manage meal plans, track fitness progress, and maintain healthy lifestyle habits.

## Technologies Used
- React
- TypeScript
- Vite
- Supabase
- PostgreSQL

## Key Features
- User authentication
- Food logging and nutrition tracking
- Meal planning
- Fitness progress monitoring
- User profile management
- Dashboard for tracking activities
